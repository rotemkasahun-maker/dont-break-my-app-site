DON'T BREAK MY APP — Support

DON'T BREAK MY APP is currently in Public Beta. If something feels confusing or the extension misses a breakage, we’d like to hear about it.

Report a problem

Use Report a problem on the results screen in the extension. You can choose a category and optionally add details. Detailed report upload is not currently supported.

Basic troubleshooting

  1. Close and reload the extension popup.
  2. Refresh the page you are checking.
  3. Save a new working baseline while the page is in the state you want to keep.
  4. Run Check again.

What to include in a support request

Please describe what you expected, what you saw, and which troubleshooting steps you tried. Do not send passwords, private page content, or customer information.
